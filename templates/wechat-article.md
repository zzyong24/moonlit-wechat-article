# 公众号长文模板（v1.1）

> **框架选择**：PAS / AIDA / SCQA / BAB / 4P

---

## 文件名格式

```
MMDDHHMM-[纯中文主题]-公众号.md
```

---

## ⚠️ 图片嵌入规范（v0.5.2 必读）

**用 `![alt](相对路径)` 嵌入图片**——不是文字说明：

```markdown
✅ 正确（图片真嵌入）：
![配图 1：3件事钩子](assets/1-封面-3件事钩子.png)

❌ 错误（不显示图片）：
📷 **配图 1**：assets/1-封面-3件事钩子.png
```

详见 `.nomi/skills/moonlit-content-engine/references/09-file-naming.md` 的"图片嵌入规范"章节。

---

## 模板

```markdown
# 【标题】（≤28 字）

### 【副标题】（可选）

![钩子图](assets/1-XXX.png)

[钩子段 · 150-200 字 · 抓人]

> 这段必须写清读者正在遇到的问题，以及读完能获得什么；禁止用“我越来越觉得”代替判断依据。

> [!KEY] [可独立成立的核心金句；没有合格金句时删除此模块]

---

## 【正文】

[按所选框架展开]
- 2500-5000 字
- H2 + H3 多级标题
- 列表 + 表格 + 引用块 + 加粗
- 每 800-1000 字配 1 张图

### 论证骨架（写作时填写，定稿可删除）

- 核心主张：
- 用户处境/痛点：
- 旧办法缺少什么：
- 产品机制如何补上：
- 证据或亲历：
- 可观察结果：
- 适用边界：

### 坑 1：XXX
![对比表](assets/N-XXX.png)

### 坑 2：XXX
![流程图](assets/N-XXX.png)

### 坑 3：XXX
![流程图v2](assets/N-XXX.png)

### 解决方案
![正文场景图](assets/N-XXX.png)

### 视觉语义标记示例

普通的 **关键概念** 使用深色加粗；本节最重要的结果使用 ==品牌绿虚线强调==。

> [!NOTE] [定义、机制解释或必要补充；不能用来装饰普通段落]

> [!VERDICT] [全文最终判断；整篇最多一个]

---

## 【CTA】

想看完整 XXX？
**评论扣"XXX"**，我发你。

—— 月明水清深
```

---

## 自检清单

- [ ] 标题 ≤28 字
- [ ] 钩子段 150-200 字
- [ ] H2 小标题 ≥3 个
- [ ] **所有图片用 `![alt](path)` 嵌入**
- [ ] 配图 5-8 张，其中至少 2 张是月明宇航员品牌正文场景图
- [ ] CTA 明确
- [ ] 不绑产品 / 不写隐私 / 不夸大 / 不编造
- [ ] 标题与开头承诺已在正文兑现
- [ ] 功能到价值之间的因果链完整，源码不是理解前提
- [ ] 没有“我越来越觉得”和无意义、装饰性的状语、补语
- [ ] 重点模块不超过 3 个、`[!VERDICT]` 不超过 1 个、每个 H2 章节 `==关键结果==` 不超过 2 处
