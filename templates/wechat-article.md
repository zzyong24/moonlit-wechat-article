# 公众号长文模板（v1.2）

> **框架选择**：PAS / AIDA / SCQA / BAB / 4P

已有口述忠实其原意，按公众号阅读需要重组和扩写；具体长文组织方法见本 Skill 入口，模板只是可选排版示意，不锁定句序或长度。共同表达规则读当前激活 moonlit-content-engine/references/editorial-contract.md。

---

## 文件名格式

```
MMDDHHMM-[纯中文主题]-公众号.md
```

---

## ⚠️ 图片嵌入规范（v0.5.2 必读）

**用 `![alt](相对路径)` 嵌入图片**——不是文字说明：

```markdown
✅ 正确（图片真嵌入）：
![配图 1：3件事钩子](assets/1-封面-3件事钩子.png)

❌ 错误（不显示图片）：
📷 **配图 1**：assets/1-封面-3件事钩子.png
```

先按本 Skill 入口“配图准备与跨形态素材复用”盘点当前作品的解释图、视频选用原图、来源清单和用户附件；真实素材保留来源，适合的原图按公众号段落重新编排。动画、AIGC 原片和真实录屏也必须盘点，不因它们是视频而跳过；调用主入口的 GIF/动效复用路径。图文成稿交付前按主入口生成版本化 visual-coverage 记录，完成手机实际审看并运行覆盖检查器；临时纯文字稿不冒充完整图文。

## 模板

```markdown
# 【标题】（≤28 字）

### 【副标题】（可选）

![钩子图](assets/1-XXX.png)

[开头 · 长度随作者原意与阅读需要]

> 整理作者给出的开头与钩子，保留意思和语气，不为套模板改写立场。

> [!KEY] [可独立成立的核心金句；没有合格金句时删除此模块]

---

## 【正文】

[按所选框架展开]
- 写透本期命题即止，不设固定字数，不为凑篇幅新增事实或套话
- 标题层级按真实内容需要设置
- 列表 + 表格 + 引用块 + 加粗
- 产品、案例、出处和机制分别按视觉职责选图；数量和位置随正文需要决定

### 原意组织（按需使用，不进入正文）

- 作者想说的主线：
- 开头与语气：
- 已提供的经历、步骤与例子：
- 段落连接：
- 作者的结尾：

### 坑 1：XXX
![对比表](assets/N-XXX.png)

### 坑 2：XXX
![流程图](assets/N-XXX.png)

### 坑 3：XXX
![流程图v2](assets/N-XXX.png)

### 解决方案
![正文场景图](assets/N-XXX.png)

### 视觉语义标记示例

普通的 **关键概念** 使用深色加粗；本节最重要的结果使用 ==品牌铜橙虚线强调==。

> [!NOTE] [定义、机制解释或必要补充；不能用来装饰普通段落]

> [!VERDICT] [全文最终判断；整篇最多一个]

---

## 【CTA】

想看完整 XXX？
**评论扣"XXX"**，我发你。

—— 月明水清深
```

## 自检清单

- [ ] 标题 ≤28 字
- [ ] 开头准确承接作者原意，长度服务理解
- [ ] 小标题数量按内容层次决定，不为凑数拆段
- [ ] **所有图片用 `![alt](path)` 嵌入**
- [ ] 已查看本作品的视频／参考素材与本轮附件，适合正文的原图按阅读顺序复用；关键事件与状态变化有对应正文和画面，不能用产品标志替代；不固定图片数量或强制增加宇航员装饰图
- [ ] 软件画面有清楚的名称与中文用途说明，实际图片与文章使用清单一致
- [ ] 只有作者本意或本次任务需要CTA时保留，不强加评论引导
- [ ] 不绑产品 / 不写隐私 / 不夸大 / 不编造
- [ ] 标题与开头承诺已在正文兑现
- [ ] 与作者原意一致，没有新增观点审查、免责或规避性段落；必要解释和长文衔接已展开
- [ ] 保留作者有意表达，整理无意重复与卡口语句
- [ ] 重点模块不超过 3 个、`[!VERDICT]` 不超过 1 个、每个 H2 章节 `==关键结果==` 不超过 2 处
